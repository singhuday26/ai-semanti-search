# Semantic Search System

Trademarkia AI/ML Engineer Assignment

This project implements a semantic search system for the 20 Newsgroups
dataset with the following components:

• Sentence-transformer embeddings (MiniLM-L6-v2)  
• UMAP dimensionality reduction  
• Gaussian Mixture Model fuzzy clustering  
• Cluster-indexed semantic cache built from scratch  
• FastAPI service exposing semantic query endpoints  

The goal of the system is to demonstrate both machine learning reasoning
and production-quality backend engineering.
